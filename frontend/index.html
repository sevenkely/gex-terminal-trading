Apparence

direct : prix du contrat futures brut · anchor : les variations Rithmic pilotent l'onglet cash sans saut de basis. Seuls les paramètres non secrets sont conservés dans data/rithmic_config.json ; le mot de passe reste en mémoire ou dans l’environnement. Aucun plant d’ordres ou P&L n’est connecté. Les gateways de production peuvent exiger le test de conformance Rithmic ; utilisez d'abord « Rithmic Test » ou le gateway fourni par votre broker. Système servi : le gateway public rituz00100.rithmic.com:443 ne sert que « Rithmic Test » ; « Rithmic Paper Trading » n'existe que sur les gateways rprotocol-ie / -de / -sg. Utilisez « Découvrir systèmes & gateways » (templates 16 + 20, sans identifiant) pour lire la liste exacte avant de saisir un system_name. La conformance authentifie mais ne relaie pas les flux CME : les prix restent différés ou figés, et un contrat explicite (ex. ESM6) évite l'échec de résolution du front-month.
