# Instrument identity marks

Local PNG copies from https://github.com/nvstly/icons (retrieved 2026-10-17).

Sources: `crypto_icons/BTC.png`; `ticker_icons/SPGI.png`, `STT.png`, `IVZ.png`,
`CME.png`. NQ deliberately uses the actual exchange mark, rather than a
Nasdaq issuer logo.

Mapping: BTC → Bitcoin; SPX → provider S&P Global; SPY → issuer State Street;
QQQ → issuer Invesco; GLD → distributor State Street; ES/NQ/GC → CME Group.
Tooltips explicitly identify the issuer/provider/exchange, not a fabricated
individual contract or ETF logo. All images load locally, without a third-party
request from the browser. Unknown instruments keep their textual symbol.
