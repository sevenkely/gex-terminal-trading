# Everything Claude Code — sélection locale

Source : https://github.com/affaan-m/everything-claude-code
Révision consultée : `76aaa77df6adc5b889e689007bf99b9a4f74af34`.
Consultation et intégration : 18 octobre 2026.

Six guides `SKILL.md` sont conservés dans leur forme upstream, avec la licence
MIT du dépôt (`ECC-LICENSE`) : frontend-patterns, frontend-design-direction,
design-system, react-performance, security-review et verification-loop.

Il s'agit de guides de travail project-scoped, pas d'un runtime Claude installé
ni d'agents exécutés automatiquement. Aucun hook distant, accès credentials ou
script d'installation de l'ensemble du dépôt n'est activé. Les recommandations
ont été adaptées au contexte Vite/FastAPI existant : références utilisateur plutôt
qu'une recherche concurrentielle forcée, graphiques impératifs, données réelles
ou fixtures identifiées, migration progressive et vérifications reproductibles.

Application concrète et limites : `terminal-react/DESIGN.md` et
`docs/REACT_MIGRATION.md`.
